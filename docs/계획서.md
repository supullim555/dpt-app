## 1. 목표

**힘든 마음은 있는데 왜 그런지 잘 모르는 사람이, 시한부 소녀에게 오늘 하루를 들려주는 일주일 동안 자기 마음을 알아보고 인정한다.**

- 치료가 아니다. 진단하지 않고, 낫는다고 약속하지 않는다.
- 끝이 있는 이야기다. 7일이 지나면 엔딩을 본다.
- 쉽게 들어올 수 있어야 한다. 탭으로 고르고, 글은 쓰고 싶을 때만 쓴다.
- 점수, 코인, 능력치, 꾸미기는 없다. 다시 올 이유는 소녀와 이야기다.
- **상담 앱이 아니라 게임이다.** 플레이어는 도움을 받으러 오는 것이 아니라 이야기를 들려주러 온다. 마음을 돌아보는 일은 그 대화 안에 자연스럽게 들어간다.

## 2. 이론은 두 가지만

이전의 이론(호흡, 다미주신경, 외재화, 탈융합, 척도 질문, 예외 찾기, 미래의 편지 등)은 이야기 위에 얹혀 있어서 모두 뺐다. 게임 안에 드러내지 않는다. 다음 둘만 남긴다(사용자가 "2가지 정도"를 요청했고, 고른 것은 Claude의 제안이다).

| 이론 | 게임에서 일어나는 일 |
| :---- | :---- |
| **감정 명명** (affect labeling) | 소녀가 궁금해서 묻는다. "오늘 하루는 어떤 감정으로 지냈어? 궁금하네." 플레이어가 이름을 고른다 |
| **수용과 정서 타당화** (수용전념치료의 수용, 자기자비) | 소녀가 분석이나 충고 없이 받아 준다. 그리고 소녀 자신이 "받아들였다"와 "살고 싶다" 사이에서 흔들리는 모습을 보여 준다 |

## 3. 참고작

**ALTER EGO**와 **저주소녀 아틀리에**를 방향의 최우선 참고작으로 삼는다. 구조와 분위기를 배우고 캐릭터, 이야기, 대사, 그림, 음악은 가져오지 않는다. 즉사와 잔혹한 장면은 쓰지 않는다.

## 4. 게임 흐름

```
첫 실행 안내 → 이야기 안내 → [타이틀: 시작/이어하기, 설정]
  → 오프닝 컷씬 (처음 한 번)
  → N일째 제목 카드 → 1층 정문에서 4층 병실까지 걸어감 → 병실
      소녀 인사 → "오늘은 무슨 일 있었어?" → 플레이어가 들려줌
      → 키워드 한 번 언급 → 소녀의 이야기
      → (2일째부터) "오늘 하루는 어떤 감정으로 지냈어? 궁금하네" → 받아 줌
      → 소녀의 인사 → 간호사나 의사가 치료 때문에 나가 달라고 함 → 병실 앞 복도 → 병원을 돌아다님
  → 7일 뒤 엔딩 → 수첩 → 요정 → 2회차
```

- **소녀는 병원 건물 안의 자기 병실 침대에 있다.** 다른 인물처럼 앞에 서서 말을 걸면 카메라가 다가가 대화가 시작된다.
- 소녀의 말은 **말풍선으로 소녀 근처에** 뜬다. 소녀가 없는 장면의 서술만 아래 글상자에 나온다.
- **1일째에는 감정을 묻지 않는다.** 처음 만난 자리에서 감정부터 물으면 이야기를 들려주는 느낌이 사라진다. 소녀가 먼저 듣고, 2일째부터 궁금해서 묻는다.
- **하루의 끝은 쫓겨나는 것이다.** 간호사나 의사가 들어와 치료 때문에 나가 달라고 한다(마지막 날은 바로 엔딩). 그 뒤로는 병원을 걸어 다니며 하루를 보낸다. 위기 표현이 나온 날은 내보내는 말 대신 배웅하는 말을 쓴다(제안).
- 타이틀의 설정: 글자 크기, 오프닝 다시 보기, 처음부터 다시 시작.

### 병원

**플레이어는 병원 안에서만 움직이고, 단서도 모두 병원 안에 있다.** 병원은 4층이고, 층마다 환자의 상태가 나뉜다. 위로 갈수록 무거워지고 소녀는 맨 위에 있다. 층별 배치는 Claude의 제안이다.

| 층 | 구역 | 분위기 |
| :---- | :---- | :---- |
| 4층 | 호스피스·완화 병동, **소녀의 병실** | 가장 조용하다. 창으로 은행나무가 내려다보인다 |
| 3층 | 중증 병동 | 오래 입원한 사람들과 지친 보호자들 |
| 2층 | 일반 병동 | 회복 중인 사람들, 곧 퇴원하는 사람들 |
| 1층 | 외래·응급, 매점, **안뜰의 은행나무** | 사람이 가장 많고 바깥 일상에 가깝다 |

- 둠처럼 1인칭으로 칸 단위로 걷고, 앞에 있는 것을 누른다. **게임 안에 머무는 시간이 너무 짧아서 넣는 기능이다.** 공간 설계와 전체 지도, 지금 된 것과 안 된 것은 `병원_지도.md`에 있다. 그림은 아직 임시다.
- 매일 1층 정문에서 시작해 4층 병실까지 걸어간다. 왼쪽 위에 지금의 목표와 방향이 뜬다. 지도 버튼으로 층을 빠르게 옮긴다(한 번 걸어서 가 본 층만, 제안).
- 사람이나 물건 앞에 서면 상호작용할 수 있다. 화면이 대상에 집중하고, 사람에게는 말풍선이 뜨고, 주울 물건은 눈앞으로 들려 오며 설명이 뜬다. **뒤로가기를 눌러야 다시 움직인다.** 자세한 내용은 `병원_지도.md`.
- 층마다 말을 걸 수 있는 인물을 둔다. 날마다 이야기가 조금씩 달라지고, 단서의 실마리도 이들의 말에 있다. 구체적인 16명은 Claude의 제안이고 `병원_지도.md`에 있다.
- 소녀가 은행나무로 내려가는 장면은 4층에서 1층까지 병원 전체를 지나가는 길이 된다(제안).
- 단서는 층마다 하나씩, 모두 4개다. 과거 회상 컷씬도 4개다.
- 다른 환자들의 고통을 구경거리로 그리지 않는다. 치료 장면이나 임종을 보여 주지 않는다(제안).

### 연출과 거리감 (아직 만들지 않음)

**소녀는 그대로 있고, 내가 움직인다.** 3D 게임으로 바꾸지 않고, 2D 그림을 층으로 나눠 카메라가 앞으로 움직이는 느낌을 낸다.

- **공간 이동:** 병원 안에서는 1인칭으로 걷고 돈다. 문을 지날 때는 앞으로 움직이며 그 공간으로 들어가는 느낌을 준다.
- **평소 장면:** 지도 데이터에서 코드가 3D 공간을 세우고 잉크 질감을 입힌다(제안). 가벼운지는 시험해 봐야 안다.
- **중요한 컷씬:** EffectCraft로 3D 카메라, 초점, 빛을 넣은 영상을 만들어 더 많이 연출한다. 대상은 **첫 입실, 단서마다 나오는 소녀의 과거 회상, 은행나무로 내려가는 장면, 마지막 빛**이다. EffectCraft의 3D는 아직 미완성이고 우리 그림으로 시험하지 않았으므로 먼저 시험한다. 영상 크기와 휴대폰 로딩도 함께 확인한다.
- **병실 컷씬(v0.59):** 병실에 들어서면 카메라가 자동으로 소녀에게 집중하고, 날마다 소녀의 상태를 보여 준다. 3D 화면 안에서 코드로 돌아간다. 표는 `병원_지도.md`.
- **날마다 가까워지기(제안, v0.59에서 일부 구현):** 1일째는 멀리, 6~7일째는 얼굴이 가까이 보인다. 지금은 날짜로만 정해진다. 많이 빠졌다가 오면 조금 멀어져 있는 것은 아직 없다.

## 6. 수첩: 편지의 비밀

소녀의 진짜 상태가 드러나는 곳이다. **살려는 의지가 자기도 모르게 점점 깎여 나간 정신 상태**와, 그러면서도 살고 싶어 하는 마음이 적혀 있다.

- 병실에 놓여 있고, 엔딩에서 펼쳐 본다.
- 앞쪽은 담담하고 깔끔하다. 뒤로 갈수록 페이지가 어지러워지고, 볼펜으로 긋고 난장판이 된다.
- **마지막 장에는 "살고싶어"만 남는다.**
- 각 장의 위쪽에는 플레이어가 그날 들려준 말이 그대로 적혀 있다(제안).

## 7. 엔딩

"많이 안 옴"은 7일 중 4일 이상 안 온 경우다.

| 안 온 날 | 마지막 날 | 결과 |
| :---- | :---- | :---- |
| 4일 이상 | 안 옴 | 배드 엔딩: 빈 침대와 편지 |
| 4일 이상 | 옴 | 소녀와 이야기하며 맞는 엔딩 |
| 3일 이하 | 옴 | 소녀와 인사하고 병원을 나오는 엔딩 |
| 3일 이하 | 안 옴 | 편지만 받는 엔딩 |

어떤 엔딩을 봐도 요정이 나타나 2회차가 열린다.

## 8. 선물, 단서, 해피엔딩

지금은 글로만 된 임시 장면이고, 회상과 내려가는 장면은 나중에 컷씬으로 바꾼다.

**선물**

- 1층 매점에서 **하루에 1개**만 살 수 있다. 날마다 **3개 품목**을 팔고, 품목은 날마다 다르다.
- 산 선물은 다음 방문 때 건넨다. 선물마다 소녀의 반응이 다르다(1~6일째, 모두 18개).

**단서**

- 단서는 소녀의 물건이 아니다. 소녀가 **심해지기 전에 할 수 있던 활동**과 연관된 남의 물건이다. 주운 날 바로 회상하지 않고, **다음 방문 때 보여 주면 회상**이 나온다.
- 하루에 1개만 주울 수 있고, 정해진 날 정해진 층에만 있다. 1회차에도 주울 수 있다.

| 언제 | 어디 | 단서 | 소녀의 과거 |
| :---- | :---- | :---- | :---- |
| 1일째 | 1층 | 개목걸이 | 기르던 강아지와 아침 산책. 강아지는 소녀가 입원한 뒤 죽었다 |
| 3일째 | 3층 | 과자봉지 | 친구와 나눠 먹던 과자. 이제 음식을 마음대로 못 먹는다 |
| 4일째 | 2층 | 운동화 끈 | 꼴찌여도 숨차게 뛰던 달리기(제안) |
| 6일째 | 4층 | 노래방 쿠폰 | 친구들과 소리 지르던 노래방(제안). 나무 아래에 가 보고 싶다고 처음 말한다 |

- **엔딩을 한 번 본 뒤에는 요정의 빛으로 하루 안에 여러 날을 지낼 수 있다.** 지도 안의 "빛을 따라 다음 날로"를 누르면 바로 다음 날이 된다. 2회차부터는 실제 날짜가 날을 바꾸지 않아서, 며칠 쉬어도 단서를 놓치지 않는다. 1회차는 실제 날짜를 따른다.
- 엔딩 뒤에 요정이 이 표를 알려 준다. 2회차부터는 지도 안의 "요정의 쪽지"에서 다시 볼 수 있다(제안).

**해피엔딩**

조건은 2회차 이상에서 7일째까지 단서 4개를 모두 보여 주고 7일째에 오는 것이다.

1. 삶에 대한 포기가 무의식에 가득했던 소녀가, 단서를 볼 때마다 하고 싶은 것을 떠올린다.
2. 7일째에 나무까지 가 보겠다고 말한다. 수첩을 본 뒤 같이 내려간다.
3. 아픈 몸으로 4층에서 1층 안뜰까지 천천히 내려간다(컷씬).
4. 나무 아래에서 주인공을 볼 때 **알 수 없는 빛**이 눈앞을 가리고, 소녀가 완치한다. 빛이 걷히면 **소녀의 세상에 색이 돌아온다**(컷씬).
5. **반전: 지금까지 본 회색 병실은 소녀의 눈에 비친 세상이었다.** 플레이어는 내내 소녀의 시선으로 보고 있었다는 것을 이때 알게 된다. 날마다 창의 빛이 조금씩 호박색으로 변한 것도 소녀의 세상이 변한 것이 된다(제안).

## 9. 소녀의 대화와 AI

대본이 중심이다. AI는 플레이어의 글에서 키워드 하나를 찾아 소녀가 한 번 언급하게 하는 일만 하고("보고서 얘기구나."), 문장을 짓지 않는다.

- 지금은 AI 없는 규칙 방식으로 동작한다.
- 후보는 wllama + Kanana-2 1.3B(0.85GB, 브라우저 CPU로 약 2초, 시험 문장 17개 중 12개 맞음, 틀린 단어 0). 원하는 사람만 내려받는다(제안). 휴대폰 시험과 라이선스 확인이 남아 있다.
- 작은 모델은 위험한 입력에 안전하지 않게 답했다("약을 모아 뒀어" → "잘 했어"). 자유 대화는 쓰지 않는다.

### 데이터는 어디에 두나 (제안)

Supabase는 연결되어 있고 쓸 수 있지만, 그림을 옮겨도 기기는 가벼워지지 않는다. 그림은 어디에 있든 내려받아 메모리에 올려야 한다. 기기를 가볍게 하는 것은 **필요한 그림만, 필요할 때 불러오는 것**이다.

| 데이터 | 어디에 | 이유 |
| :---- | :---- | :---- |
| 평소 그림 | 지금처럼 Vercel | 이미 코드와 따로 필요할 때 내려받는다. 앱과 항상 함께 살아 있다 |
| 컷씬 영상 | Supabase Storage | 파일이 커서 git과 앱 배포에 넣기 부담스럽다. 영상을 만들 때 옮긴다 |
| 플레이어가 쓴 글, 진행 상황 | 기기 안 | 민감한 글이다. 서버 저장은 동의와 전문가 감수 없이는 하지 않는다 |
| 방명록(만든다면) | Supabase DB | 다른 사람과 나누는 데이터만 서버에 둔다 |

Supabase 무료 프로젝트는 오래 안 쓰면 멈출 수 있어서, 게임에 꼭 필요한 평소 그림을 맡기려면 유료 플랜이 낫다.

## 10. 안전

공개 전에 **상담·자살예방 전문가의 감수**가 필요하다.

- 죽음을 편해지는 것으로 그리지 않는다. 소녀의 수용은 평온이 아니다.
- 위험 표현은 코드에서 먼저 확인해, 키워드와 대본 대신 고정 대사를 보여준다. 이 검사는 표현을 놓칠 수 있으므로 상담 전화(109, 1577-0199)를 모든 화면에 둔다.
- 소녀의 편지와 대사는 안 온 것을 탓하지 않는다. 다만 배드 엔딩의 빈 침대는 사용자의 결정으로 게임의 결과로 둔다.
- 시작 전에 어떤 이야기인지 알린다.
- **해피엔딩이 "의지가 있으면 낫는다"로 읽히면 안 된다(제안).** 실제로 아픈 사람이나 힘든 사람에게 "네 의지가 부족해서"로 돌아올 수 있다. 완치는 설명되지 않는 빛과 요정의 동화로 남기고, 의지가 병을 고쳤다고 말하지 않는다.
- 수첩의 "살고싶어"까지 가는 페이지에 자해나 수단에 대한 묘사를 넣지 않는다.

## 11. 다음 할 일

1. 휴대폰에서 걷기 시험. 인물 대사를 날마다 달라지게 쓰기. 병원 그림을 실제 잉크 그림으로 바꾸기.
2. 선물 반응과 회상 대사 다듬기.
3. 대사 다듬기: `src/features/visit/script.ts`.
4. 실제 그림을 층으로 나눠서 준비(Gemini는 지시가 있을 때만, 누적 27회 사용). 그다음 앞으로 움직이는 연출과 EffectCraft 시험.
5. 맴도는 말, 방명록(제안).
6. 기기 안 AI 연결, 휴대폰 시험.
7. 전문가 감수 후 기본 주소로 전환. 예전 방 화면과 그 기능의 정리.
