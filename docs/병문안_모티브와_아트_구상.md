# 병문안 — 모티브와 아트 구상 v0.1

> 2026-10-31 작성. 사용자의 요청으로 **ALTER EGO**와 **저주소녀 아틀리에**를 방향의 최우선 참고작으로 삼는다.
>
> **참고하되 베끼지 않는다.** 구조와 분위기만 배운다. 두 게임의 캐릭터, 이야기, 대사, 그림, 용어(EGO, Es 등), 음악은 쓰지 않는다. 그림을 만들 때도 프롬프트에 두 게임이나 작가의 이름을 넣지 않는다.
>
> **자료:** 스토어 설명, 나무위키, 리뷰를 읽고, 사용자가 보여준 두 게임의 스크린샷 12장을 봤다. 직접 플레이한 것은 아니다.

## 1. 두 게임에서 배울 것

### ALTER EGO (Caramel Column)

| 그 게임의 특징 | 병문안에 가져올 방식 |
| :---- | :---- |
| 떠다니는 "속삭임"을 탭해서 EGO를 모으고, 그것으로 이야기를 진행 | 병실에 떠다니는 **"맴도는 말"** 을 탭해서 모은다. 플레이어가 고른 감정과 쓴 말, 소녀의 말이 조각으로 떠다닌다. 모은 것으로 선물을 산다(기획서 §9의 "선물을 어떻게 사나"에 대한 제안) |
| 차분하고 평가하지 않는 상대와 "나와 그녀에 대해" 나누는 대화 | 소녀와의 대화. 이미 같은 방향이다 |
| 성격 검사의 답이 이야기에 영향을 줌 | 날마다 한 번 **짧은 물음**을 소녀가 던진다. 답에 따라 소녀의 대사가 조금 달라진다. 점수를 매기거나 진단하지 않는다 |
| 글과 음악이 중심이고 화면은 절제됨 | 화면은 정적으로 두고 글, 음악, 빛의 변화로 분위기를 만든다 |
| 해석과 선택에 따라 달라지는 여러 엔딩, 다시 하게 만드는 구조 | 이미 같은 방향이다(엔딩 4종과 요정 2회차) |

### 저주소녀 아틀리에 (SleepingMuseum)

| 그 게임의 특징 | 병문안에 가져올 방식 |
| :---- | :---- |
| 소녀와 보내는 7일, 어두운 공간에 들어선 1인칭 | 이미 같은 구조다. 7일의 긴장감과 한 공간에 머무는 밀도를 배운다 |
| 날마다 붙는 제목(뜻이 나중에 다르게 읽힘) | 날마다 **제목 카드**. 처음엔 평범하게 읽히고, 끝까지 보면 다르게 읽힌다 |
| 소녀의 요구를 듣고 → 공간을 탐색해 물건을 찾고 → 그림에 반영 | 소녀의 **소원을 듣고 → 다른 공간에서 물건을 찾아 → 선물한다.** 사용자가 정한 "다른 공간, 선물, 숨은 기믹"과 그대로 맞물린다 |
| 전임 화가들의 기록을 읽어 이야기와 힌트를 얻음 | 병실 머리맡의 **방명록**. 이전 방문객이 남긴 쪽지에서 소녀의 이야기와 소원의 힌트를 얻는다 |
| 소녀의 진짜 사정이 조금씩 드러나는 미스터리 | 소녀에 대해 플레이어가 **조금씩 알아 가는 비밀**을 대본에 둔다. 다시 하고 싶게 만드는 힘이 된다 |
| 날마다 그림이 채워지는 눈에 보이는 진행 | **날마다 병실과 소녀가 조금씩 달라진다**(§3) |
| 엔딩 수집, 다 모으면 열리는 추가 콘텐츠 | **본 엔딩을 기록**해 두고, 모으면 소녀의 짧은 이야기가 열린다 |
| 갑자기 놀라게 하는 연출 없음, 노을이 중요한 모티프 | 놀라게 하는 연출은 쓰지 않는다. 이쪽은 **창밖의 빛**을 모티프로 쓴다 |

### 가져오지 않는 것

이 앱은 힘든 사람이 쓰는 앱이다(기획서 §8).

- **즉사와 잔혹한 장면.** 저주소녀 아틀리에의 핵심인 "틀리면 죽는다"와 데드씬은 쓰지 않는다. 힘든 사용자에게 해로울 수 있다.
- **공포를 위한 공포.** 미스터리와 쓸쓸함은 쓰되, 소녀나 병실이 플레이어를 위협하지 않는다.
- **플레이어의 내면을 몰아붙이는 독백과 진단처럼 보이는 결과.**
- **과금과 광고로 진행을 재촉하는 구조.**

## 2. 게임 뼈대

```
[제목 화면]
   ↓
[N일째 제목 카드]
   ↓
[병실 문 앞] ──→ [다른 공간] 물건 찾기·맴도는 말·숨은 기믹
   ↓                 ↑
[병실] ←─────────────┘
   ├ 맴도는 말 탭하기 (선택, 언제든)
   ├ 방명록 읽기 (선택)
   ├ 선물 건네기 (있을 때)
   └ 소녀와 이야기: 감정 → 오늘 하루 → 키워드 한 번 → 소녀의 대본 → 소녀의 물음
   ↓
[병실을 나옴] 창밖의 빛이 바뀌어 있다
   ↓ 7일 뒤
[엔딩 4종] → [나눈 이야기 돌아보기] → [요정] → [2회차: 소원·선물·기믹을 맞추면 해피엔딩]
```

- **입구는 가볍게 유지한다.** 맴도는 말, 방명록, 다른 공간은 모두 선택이다. 들어가서 하루 이야기만 하고 나와도 하루가 끝난다(쉬운 접근성, 계획서 §1).
- 지금 `?visit=1`의 뼈대는 위에서 맴도는 말, 방명록, 선물, 다른 공간, 제목 카드, 물음, 해피엔딩이 빠진 상태다.

## 3. 아트 방향

v0.40에 사용자가 보여준 스크린샷을 보고 다시 썼다. 처음의 "저채도 페인팅" 구상은 추정이었고 틀렸다.

### 스크린샷에서 확인한 공통점

- **흑백에 강조색 하나.** ALTER EGO는 하늘색 나비, 저주소녀 아틀리에는 빨간 눈과 숫자.
- **거친 잉크 선.** 칠보다 선이 분위기를 만든다. 아틀리에는 검은 공간에 스포트라이트.
- **종이 질감 UI.** 찢어진 종이 상단, 구겨진 종이 낱말 카드, 무늬가 있는 어두운 패널, 흰 테두리 글상자.
- **구도.** 위쪽 3분의 2는 그림, 아래는 패널. 검은 화면에 글만 얹는 영화 같은 장면.
- **말풍선.** 손으로 그린 듯한 삐뚤어진 윤곽선(아직 만들지 않음).

### 병문안만의 방향: 색이 돌아온다

- 분위기는 **쓸쓸하고 따뜻하게**(사용자 확정). 미스터리는 있지만 무섭지 않다.
- 강조색은 **은행잎의 호박색 하나**다. 나비와 빨간 눈은 쓰지 않는다.
- **색은 창문으로만 들어온다.** 1일째의 창은 거의 회색이고 7일째에 온전한 호박색이 된다.
- **해피엔딩에서 비로소 세상 전체에 색이 돌아온다.** 배드 엔딩과 편지 엔딩은 끝까지 회색이다.
- 소녀는 날마다 조금씩 플레이어 쪽으로 돌아앉는다. 날짜로만 바뀌고, 온 날이 적으면 그 변화를 놓친 채로 본다.

| 날 | 창의 빛 | 소녀 |
| :---- | :---- | :---- |
| 1 | 회색 | 창 쪽으로 돌아누움 |
| 2 | 회색, 약간 누런빛 | 고개만 돌림 |
| 3 | 옅은 호박색 | 얼굴을 보임 |
| 4 | 비, 다시 회색 | 잠든 얼굴 |
| 5 | 호박색 | 조금 일어나 앉음 |
| 6 | 진한 호박색 | 앉아서 창밖을 봄 |
| 7 | 온전한 호박색 | 플레이어를 똑바로 봄 |

### 코드로 만든 것과 그림이 필요한 것

**코드로 그렸다(`scripts/assets/draw-visit-ui.js`, 비용 없음):** 찢어진 종이, 구겨진 종이 카드, 어두운 패널, 임시 병실, 임시 소녀.

**Gemini가 필요하다(지시가 있을 때만):**

| ID | 그림 | 수량 |
| :---- | :---- | :---- |
| B1 | 병실 (창이 뚫린 흑백 잉크화, 빈 침대 겸용) | 1 |
| C1~C5 | 소녀: 돌아누움, 고개 돌림, 잠듦, 앉음, 마주 봄 | 5 |
| C6 | 나은 소녀 (해피엔딩, 전체 컬러) | 1 |
| E1~E2 | 편지 클로즈업, 병원을 나서는 길 | 2 |
| F1 | 요정 (작은 빛에 가깝게) | 1 |
| S1~ | 다른 공간과 물건 | 공간이 정해진 뒤 |

### 그림 프롬프트 초안

**사용자가 보여준 스크린샷을 참고 이미지로 넣지 않고, 게임이나 작가의 이름도 쓰지 않는다.** 스타일은 말로만 설명한다.

```
Monochrome black and white ink illustration, rough hand-drawn lines, visible pen
strokes and grey wash, deep blacks, quiet and melancholic but warm. No color at all.
No text. No horror, no blood, no medical equipment close-ups. Portrait orientation.
```

- **C5:** `A teenage girl with long dark hair sitting up in a hospital bed in plain patient clothes, looking straight at the viewer with a small tired gentle expression. Waist-up.`

청소년 캐릭터이므로 옷차림과 묘사는 단정하게 제한한다.

### 호출 계획

1. **1차 시험 (약 3회):** B1, C1, C5. 분위기가 맞는지, 같은 소녀로 보이는지 확인한다.
2. **2차 (약 7회):** 나머지 소녀, 편지, 나서는 길, 요정.
3. **3차:** 다른 공간과 물건.

실패하면 호출이 늘 수 있다.
